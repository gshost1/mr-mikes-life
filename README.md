# Mr. Mike's Life

A cozy, pixel-art, third-person 3D browser game about Mr. Mike the cat: salad breakfasts, bathtub water, sunbeams, chair theft, biscuits, knocking things off tables, and zoomies.

- `mission-brief.md`: the build brief
- `cat-notes.md`: everything about Mr. Mike and the game design
- `ui-draft-pixel.html`: the pixel UI style reference
- `reference/mr-mike.jpeg`: the real Mr. Mike

It's hosted on Vercel (Hobby). Every push to `main` deploys automatically.
